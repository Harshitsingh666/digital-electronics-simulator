# Interactive Logic Gate Simulator and Truth Table Generator

An educational, browser-based digital electronics lab for exploring logic gates, Boolean expressions, truth tables, and small circuits. It runs locally with no backend, database, libraries, or external services.

## Features

- Eight logic gates: AND, OR, NOT, NAND, NOR, XOR, XNOR, and Buffer
- Interactive binary switches, live SVG circuit diagrams, signal colors, and LED outputs
- Automatically generated truth tables with current input highlighted
- CSV export with headers
- Half adder, full adder, 2-to-1 multiplexer, SR latch, and rising-edge D flip-flop
- Beginner-friendly Learn section and 10-question multiple-choice quiz
- Responsive layout, keyboard-operable controls, and light/dark theme

## Technologies

HTML5, CSS3, and vanilla JavaScript (ES6). No build step or dependencies.

## Run locally

1. Open `index.html` directly in a modern browser, or serve this folder with any static web server.
2. Choose a gate or circuit from the left panel.
3. Toggle inputs; the diagram, output, and highlighted truth table row update together.
4. Select **Download as CSV** to save the selected component's table.
